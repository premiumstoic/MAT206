2D Particle Diffusion
& Reaction Kinetics

Continuous random walks driven by temperature, activation energy, and spatial environment.

Context

Previous weeks modeled diffusion on a discrete lattice. This week we switch to a continuous space model: each particle undergoes Brownian motion using a Gaussian random walk. The diffusion coefficient is calculated from temperature and activation energy via the Arrhenius equation, and it varies depending on spatial environment.

01

Continuous Random Walk (Brownian Motion)

At every timestep Δt, each particle's displacement is sampled independently from a Gaussian distribution with mean 0 and variance 2·D·Δt:

Δx ~ N(0, 2·D·Δt) Δy ~ N(0, 2·D·Δt)

The standard deviation of each step is σ = √(2·D·Δt). A larger D or larger Δt means bigger steps and faster apparent diffusion.

02

Arrhenius Kinetics

The diffusion coefficient D depends on temperature via the Arrhenius equation:

D = D₀ · exp(−Eₐ / (R · T))
D₀
Pre-exponential factor (µm²/s). Max diffusivity at infinite T.
Eₐ
Activation energy (J/mol). Suppresses diffusion at low T.
R
Ideal gas constant = 8.314 J/mol/K.
T
Temperature (Kelvin). Powerful lever for diffusion speed.

D is expressed in physical units (µm²/s), but the canvas renders in pixels. The conversion uses a user-defined scale a (µm/pixel):

D_pixels = D_µm / a²

🔬 Exploration Questions

Question 1 — Temperature Sensitivity

What happens to particle speed as you dramatically increase or decrease temperature?

Increasing T exponentially increases D (Arrhenius), so particles move much faster. Decreasing T sharply reduces D. Below a threshold temperature, Eₐ overwhelms the thermal energy and particles become nearly frozen.

Question 2 — Membrane Barrier

Initialize all particles on the Left side, set Env 2 to "Membrane" with high Eₐ. How does the membrane affect crossing?

With low temperature or very high Eₐ,₂, the membrane region has near-zero D. Particles that wander into the membrane diffuse so slowly that very few cross to the other side — acting as an impermeable barrier.

Question 3 — Scale Factor

What is the physical effect of changing the µm/pixel scale factor?

A smaller scale 'a' means each pixel represents fewer micrometers ("zoomed in"). This increases D_pixels, making particles appear to move faster on screen even though the physical diffusivity hasn't changed.

function randGauss(sigma) { let u = 0, v = 0; while (u === 0) u = Math.random(); while (v === 0) v = Math.random(); return sigma * Math.sqrt(-2 * Math.log(u)) * Math.cos(2 * Math.PI * v); } function reflect(val, min, max) { if (val < min) return min + (min - val); if (val > max) return max - (val - max); return val; }
