Grain Growth

How curvature-driven boundary migration makes small grains vanish and large grains dominate.

Context

Polycrystalline materials consist of many small crystallites (“grains”) separated by grain boundaries. Over time, the system reduces its total boundary energy by migrating these boundaries — small, highly-curved grains shrink and are eventually consumed by their larger neighbors. This process is called grain growth and can be simulated with a Monte Carlo lattice model using Glauber kinetics.

01

The Lattice Model

Each cell in a 2D grid is assigned a discrete orientation (1 of 3 or 6 possible values). Cells sharing the same orientation belong to the same grain. We use an 8-neighbor Moore neighborhood with periodic boundary conditions (the grid wraps around like a torus).

02

Energy & Glauber Acceptance

Ecell = Σ (Ebulk if same, Egrain if different) ΔE = Efinal − Einitial Paccept = 1 / (1 + exp(ΔE / T))
03

MC Trial Logic

  1. Pick a random cell.
  2. Examine its 8 neighbors (periodic wrapping).
  3. Optimization: If all 8 neighbors match → skip immediately.
  4. Build an invasion pool of different neighbor orientations.
  5. Randomly choose one invading orientation.
  6. Compute ΔE and apply the Glauber criterion.

🔬 Exploration Questions

Run the simulation with different parameters to answer these physical analysis questions.

Question 1

What is the effect of having bulk/boundary energy difference being too big or very close?

Energies very close: ΔE for any proposed flip is very small. The Glauber acceptance probability tends toward 50%. Boundaries dissolve into random, fuzzy noise because thermal fluctuations easily overpower the weak boundary energy penalty.

Energies far apart: ΔE becomes very large. Unfavorable moves get acceptance probability of virtually 0%, favorable moves get 100%. The system becomes deterministic and will freeze in local minima without thermal jiggling.

Question 2

Which curvature wins (negative or positive)? Why?

Convex surfaces (curving outward, small grains) lose and are consumed by concave surfaces (large grains). A cell protruding outward has more unlike neighbors, giving it a higher energy penalty. To minimize energy, it flips to match the surrounding grain. Boundaries inherently migrate toward their center of curvature.

Question 3

What happens to the grain size? Why?

The average grain size continuously increases. Small, highly-curved grains shrink and disappear. As fewer grains remain in the same total area, the mean grain size necessarily grows.

Question 4

Does low or high temperature change these tendencies?

High Temperature: Increases the denominator in ΔE/T, driving acceptance probability closer to 50% for all moves. Introduces more random noise.

Low Temperature: Makes the system highly directional, only accepting moves that strictly lower local energy.

Question 5

Does the temperature change the grain size change rate?

Yes, higher temperature increases the growth rate. Boundaries in a lattice are jagged; smoothing them often requires a temporary, unfavorable energy increase. Low temperatures cause the system to freeze in local energy minima. Higher temperatures provide the thermal energy to overcome these barriers, allowing boundaries to migrate freely and grains to grow faster.

04

Under the Hood: MC Trial

The core Monte Carlo trial with skip optimization and Glauber acceptance:

// Pick random cell const r = Math.floor(Math.random() * rows); const c = Math.floor(Math.random() * cols); const ori = grid[r * cols + c]; // Check 8 neighbors (periodic) let allSame = true; for (const [dr, dc] of MOORE) { const nOri = grid[pmod(r+dr, rows) * cols + pmod(c+dc, cols)]; if (nOri !== ori) allSame = false; } if (allSame) continue; // skip homogeneous // Glauber acceptance const ratio = dE / T; const pAccept = ratio > 50 ? 0 : ratio < -50 ? 1 : 1 / (1 + Math.exp(ratio));
