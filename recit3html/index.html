Assignment 03

2D Binary Phase
Transformation

Two elements, two crystal structures, one thermodynamic competition.

Context

This simulation models how a mixture of two atomic species (A and B) and vacancies evolve on a 2D lattice. Unlike Weeks 1–2 which dealt with a single species, now the system must balance phase separation (AA and BB clusters forming, AB mixing penalized) with crystal structure competition (4-coordination vs 8-coordination). Two distinct kinetic mechanisms — diffusion and coordination flips — drive the system toward its ground state.

01

Two Kinetic Mechanisms

The simulation models two distinct physical processes, controlled by the Diffusion / Flip slider:

  • Diffusion (Swap Move): An atom physically migrates to an adjacent vacant lattice site. This represents mass transport.
  • Flip (Coordination Change): The atom stays physically stationary but switches its crystal packing configuration between 4-coordination and 8-coordination. This represents a local structural phase transformation.

The default 80/20 setting simulates a reaction-limited process: atoms move around easily, but the structural transformation is the bottleneck — analogous to the slow oxidation of iron.

02

Thermodynamics & Interaction Energies

Evolution is driven by minimizing internal energy. The local energy depends on pairwise interactions:

E_AA
−10
Weakly attractive
E_BB
−50
Strongly attractive
E_AB
+50
Highly repulsive

Because same-species interactions are negative (favorable) and cross-species positive (unfavorable), the system is thermodynamically driven to phase separate. B clusters are the most tightly bound.

03

Glauber Dynamics

Each proposed move is accepted/rejected using Glauber dynamics. For a move with energy change ΔE:

q = exp(−ΔE / T) p = q / (1 + q)
  • Low T: System strictly obeys energy gradients — only energy-lowering moves accepted.
  • High T: p → 0.5 — moves accepted ~50% of the time regardless of ΔE (entropy dominates).
04

Crystal Coordination: 4 vs 8

  • 4-Coordination: Atom interacts with Up, Down, Left, Right neighbors only.
  • 8-Coordination: Atom interacts with all 8 directions (includes diagonals).
  • "Both" Mode: Atoms can switch between coordination states via flip moves. Coordination is shown by the outline color on each cell.

Periodic boundary conditions wrap the grid — an atom at the right edge sees the left edge as its neighbor.

🔬 Exploration Questions

Adjust the controls and observe each phenomenon. Each question targets a distinct physical behavior.

Question 1 — Baseline

Set to a single element (Init. B = 0) and force 4-coordination. How does this compare to Week 1?

With only A atoms and 4-coordination, this reduces exactly to the Week 1 Canonical MC simulation. At low T, A atoms cluster (E_AA = −10 attractive). At high T, they remain mixed. The landscape is identical — one species, one crystal structure.

Set Init. B = 0, Coordination = 4-coord, T = 50. Watch clustering behavior.
Question 2 — Energy Variations

Change E_AB from +50 to 0 or negative. How does phase separation change?

E_AB = 0: A and B are thermodynamically neutral. Clustering is still driven by E_AA and E_BB preferences, but weaker.

E_AB negative: A and B now prefer each other, forming an ordered alloy (alternating A-B-A-B) — analogous to an ordered intermetallic compound.

Try E_AB = 0, then E_AB = −50. Compare microstructures at low T.
Question 3 — Temperature Extremes

Compare the system at T = 5 (very low) versus T = 500 (very high). What drives behavior in each case?

Low T ≈ 5: Only energy-lowering moves accepted. Large, compact A-rich and B-rich domains with sharp interfaces form — enthalpy dominated.

High T ≈ 500: All moves accepted ~50% of the time. The grid becomes a random mixture — entropy dominated. This is the disordered high-T solid solution phase.

Run at T = 5, then T = 500. Note how fast each approaches equilibrium.
Question 4 — Crystal Segregation

In "Both" coordination mode at low T, which crystal structure does each species prefer? Does temperature change the outcome?

B atoms (E_BB = −50) strongly prefer 8-coordination — more neighbors means more energy savings. A atoms with weaker bonds may settle in either coordination depending on the local environment. At high T, both states equalize (~50/50). Watch the dashboard to track % 8-coord A vs B over time.

Set Coordination = Both, T = 50. Run to equilibrium and check the dashboard stats.
Question 5 — Pure Phases

Is it possible to achieve a purely 4-coord or purely 8-coord system when "Both" is active?

In principle yes, but it requires extreme conditions. Even at low T, entropy introduces fluctuations into the minority coordination state. A "pure" phase can only be approached as T → 0, or by making one state so energetically favorable that the other is essentially never accessed.

Try only A atoms, E_AA = −200, Coordination = Both, T = 1. Check if the dashboard reaches 100% 4-coord.
06

Under the Hood: Grid & Periodic Boundaries

Each cell stores both a type (A/B/Empty) and a coord (4 or 8). Periodic boundaries use modulo arithmetic:

// Cell: { type: 0=Empty | 1=A | 2=B, coord: 4 | 8 } function createGrid(n, m, initA, initB) { const flat = Array(n * m).fill(null).map((_, i) => { if (i < initA) return { type: A, coord: 4 }; if (i < initA + initB) return { type: B, coord: 4 }; return { type: EMPTY, coord: 4 }; }); // Fisher-Yates shuffle for (let i = flat.length - 1; i > 0; i--) { const j = Math.floor(Math.random() * (i + 1)); [flat[i], flat[j]] = [flat[j], flat[i]]; } return chunk(flat, n); // reshape into m rows of n } // Periodic 4-coord neighbors (wrap with modulo) function neighbors4(r, c, rows, cols) { return [ [(r - 1 + rows) % rows, c], // up (wraps) [(r + 1) % rows, c], // down [r, (c - 1 + cols) % cols], // left [r, (c + 1) % cols], // right ]; }
07

Under the Hood: Glauber Dynamics

Cell energy is computed by summing pairwise interactions with neighbors. The Glauber probability then decides acceptance:

function cellEnergy(grid, r, c, coord, eAA, eBB, eAB) { const type = grid[r][c].type; if (type === EMPTY) return 0; let e = 0; for (const [nr, nc] of getNeighbors(r, c, coord)) { const ntype = grid[nr][nc].type; if (ntype === EMPTY) continue; if (type === A && ntype === A) e += eAA; else if (type === B && ntype === B) e += eBB; else e += eAB; } return e; } function glauberProb(eCurrent, eProposed, T) { const q = Math.exp(-(eProposed - eCurrent) / T); return q / (1 + q); }
08

Under the Hood: The Flip Move

The flip move is unique — the atom stays in place but its coordination label changes. Energy is recomputed under the new coordination:

// Flip: one random filled site toggles coordination const r = Math.floor(Math.random() * rows); const c = Math.floor(Math.random() * cols); const cell = grid[r][c]; if (cell.type === EMPTY) continue; const curCoord = cell.coord; // 4 or 8 const newCoord = curCoord === 4 ? 8 : 4; const eCurrent = cellEnergy(grid, r, c, curCoord, ...); const eProposed = cellEnergy(grid, r, c, newCoord, ...); const p = glauberProb(eCurrent, eProposed, T); if (Math.random() <= p) { // Atom stays put — only coordination changes grid[r][c] = { type: cell.type, coord: newCoord }; }
