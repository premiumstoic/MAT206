Assignment 02

Grand Canonical
Monte Carlo Simulation

An open system exchanging particles with a reservoir.

Context

This simulation models a region near the triple point in a P-T phase diagram using the Grand Canonical Ensemble. Unlike the canonical (NVT) ensemble from Week 1 where particle count is fixed, the grand canonical ensemble allows the system to exchange particles with an external reservoir. The flow of particles is governed by the chemical potential (μ), which acts as the thermodynamic "pressure dial" of the reservoir.

01

System Representation & Parameters

The physical system is a 2D grid. Each cell is either filled (atom present, s = 1) or empty (vacancy, s = 0). This time the system is open — atoms can appear or disappear at any cell, representing exchange with a particle reservoir.

The key parameters are:

  • Chemical Potential (μ) — Controls particle flow. High μ pumps atoms in (high pressure → liquid). Low/negative μ sucks atoms out (low pressure → gas).
  • Interaction Energy (ε) — The bond strength between nearest-neighbor filled cells. Negative values mean attractive bonds.
  • Temperature (T) — Scales the statistical weight of state changes. (k_B = 1).
02

The Grand Potential

In the grand canonical ensemble, the relevant thermodynamic potential is the grand potential (Ω). For a single cell with state s (0 or 1):

Ω = n_f · ε · s − μ · s

Where n_f is the number of filled nearest neighbors (up, down, left, right — max 4), ε is the interaction energy, s is the cell state, and μ is the chemical potential.

When a cell is empty (s = 0), Ω = 0 regardless of neighbors. The grand potential only contributes when a cell is occupied, coupling both the local bonding environment and the reservoir pressure.

03

The Monte Carlo Step

Unlike Week 1 where we pick two cells and attempt a swap, here we pick one random cell and propose to toggle its state (fill → empty or empty → fill).

The algorithm for each step:

  1. Pick a random cell at position (r, c).
  2. Count its filled neighbors n_f.
  3. Calculate Ω_current for the cell's present state.
  4. Calculate Ω_proposed for the toggled state.
  5. Compute the weight: q = exp((Ω_current − Ω_proposed) / T)
  6. Compute the probability: p = q / (1 + q)
  7. Draw a random number. If ≤ p, toggle the cell.
04

Phase Transitions: Gas ↔ Liquid

The chemical potential μ acts as the "pressure knob" of the reservoir. By tuning μ, you can drive macroscopic phase transitions:

  • High μ (positive) — Reservoir pushes atoms into the system. The grid fills up → liquid phase.
  • Low μ (very negative) — Reservoir pulls atoms out. The grid empties → gas phase.
  • Critical μ — At the right balance between μ, ε, and T, both phases coexist. Droplets nucleate and dissolve.

A completely empty grid = gas phase and a completely filled grid = liquid phase.

05

Scientific Observations

Nucleation & Growth: When μ is near the critical value, small clusters (nuclei) form and dissolve. Occasionally, a nucleus grows large enough to become thermodynamically stable and triggers a full phase transition — this is nucleation.

Hysteresis: Slowly ramping μ up and then back down, the system doesn't reverse at the same μ value. This asymmetry is a signature of a first-order phase transition.

Surface Tension: At low temperature with a large droplet, the interface between filled and empty regions is sharp and roughly circular — minimizing surface area. This is surface tension arising naturally from the ε interaction.

Question 1

What happens when you increase the chemical potential (μ) from very negative to very positive?

Very negative μ (e.g. −300): The reservoir strongly favors removing atoms. The grid rapidly approaches a gas phase — nearly completely empty.

Very positive μ (e.g. +100): The reservoir pushes atoms into every available cell. The grid converges to a liquid phase — nearly completely full.

At intermediate μ values (near the critical point), you'll see dynamic coexistence — droplets forming, dissolving, and reforming.

Try μ = −300, then μ = +100, then μ = −100 at T = 100, ε = −50.
Question 2

How does the interaction energy (ε) affect the sharpness of the phase transition?

Strongly negative ε (e.g. −100): Bonds are very strong. The transition between gas and liquid is abrupt — a first-order phase transition.

Weakly negative ε (e.g. −10): Bonds are weak, so the transition is gradual. At very small |ε|/T, the system behaves almost independently per cell.

Compare ε = −100 vs ε = −10 at the same T and μ. Notice the cluster edges.
Question 3

Start with an empty grid and slowly increase μ. Then slowly decrease it back. Do you see the same transition point?

No — this is hysteresis. When increasing μ, the system may remain in the gas phase past the equilibrium transition point because forming the first nucleus requires overcoming an energy barrier.

Going back, the filled state persists to lower μ values. The forward and backward transition points differ — a signature of a first-order phase transition with metastable states.

Try this with ε = −50, T = 50. Slowly ramp μ from −200 to 0 and back.
Question 4

How does this Grand Canonical simulation differ from the Week 1 Canonical simulation?

Canonical (Week 1): Fixed particle count. Two cells swapped. Models a closed system — studies diffusion at constant composition.

Grand Canonical (Week 2): Variable particle count. One cell toggled. Models an open system — studies phase transitions (gas ↔ liquid) controlled by external pressure (μ).

Run both simulations side by side (open recit1 in another tab) to compare their behavior.
Question 5

At low temperature with a stable droplet, observe the interface. What do you notice about its shape?

At low T, the droplet develops a roughly circular interface. This is surface tension in action — the system minimizes interface length because every exposed surface atom costs energy. A circle minimizes perimeter for a given area.

At high T, the interface becomes rough and fractal-like — the roughening transition.

Set T = 20, ε = −50, μ = −100, fill half the grid, and watch the droplet shape evolve.
06

Under the Hood: State & Grid

The simulation manages state with vanilla JavaScript. The grid is initialized and random cells are filled:

// ─── Grid creation ─────────────────────── function createGrid(n, m, filledCount) { const grid = Array.from({ length: m }, () => Array(n).fill(0)); let placed = 0; while (placed < filledCount && placed < n * m) { const r = Math.floor(Math.random() * m); const c = Math.floor(Math.random() * n); if (grid[r][c] === 0) { grid[r][c] = 1; placed++; } } return grid; }
07

Under the Hood: The Grand Canonical Step

The core difference: we pick one cell and compute the grand potential for both its current state and the toggled state:

function simulationStep() { // 1. Pick a random cell const r = Math.floor(Math.random() * rows); const c = Math.floor(Math.random() * cols); // 2. Count filled neighbors const n_f = countFilledNeighbors(grid, r, c, rows, cols); // 3. Current state const s = grid[r][c]; // 0 or 1 // 4. Grand potential: Ω = n_f · ε · s − μ · s const omega_current = n_f * eps * s - mu * s; const omega_proposed = n_f * eps * (1-s) - mu * (1-s); // 5. Weight & probability const q = Math.exp((omega_current - omega_proposed) / T); const p = q / (1 + q); // 6. Accept or reject if (Math.random() <= p) { grid[r][c] = 1 - s; filledCount += (s === 1) ? -1 : 1; } }
08

Under the Hood: Neighbor Counting

Energy depends on filled nearest neighbors. We use strict boundary conditions (walls):

function countFilledNeighbors(grid, r, c, rows, cols) { let count = 0; if (r > 0 && grid[r-1][c] === 1) count++; if (r < rows - 1 && grid[r+1][c] === 1) count++; if (c > 0 && grid[r][c-1] === 1) count++; if (c < cols - 1 && grid[r][c+1] === 1) count++; return count; }
