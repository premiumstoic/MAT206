Ostwald Ripening

Mean-field coarsening of circular particles driven by curvature and Arrhenius kinetics.

Step 01

Thermodynamics & Kinetics

Atomic mobility follows the Arrhenius equation with kB = 8.617×10−5 eV/K:

M(T) = M₀ · exp(−Q / kBT)

The critical radius is the harmonic mean of all particle radii:

Rc = ( (1/N) · Σ(1/ri) )−1

The rate of change follows the diffusion-controlled growth law:

dri/dt = (M / ri²) · (ri / Rc − 1)

Particles with r > Rc grow, while those with r < Rc shrink and dissolve.

Step 02

Numerical Substepping

The 1/ri² term makes small particles evolve extremely rapidly. We use adaptive substepping inside each dt:

nsub = max(10, ⌈dt · M / rmin² · 2⌉)

Particles below Rmin during any sub-step are immediately removed.

🔬 Exploration Questions

Question 1

Effect of T, Q, and M₀ — which has a faster effect?

T and Q reside inside the exponent of the Arrhenius equation, so changes have an exponential effect. M₀ is a linear multiplier — doubling it doubles the rate. Conclusion: T and Q have a much more profound effect.
Question 2

How do different initial size ranges affect the outcome?

Broad distribution: Massive driving force causes rapid initial coarsening. Homogeneous (Max=Min): All radii equal Rc, so dr/dt = 0 — the system is metastable until floating-point noise or Brownian motion breaks symmetry.
Question 3

Ultimate Fate: one particle or a critical size?

The system evolves into one single massive particle. Ostwald ripening minimizes total interfacial energy; the lowest energy state is a single sphere with minimum surface-area-to-volume ratio.
Step 03

Under the Hood: Radius Update

The core radius-update loop with adaptive substepping:

// Arrhenius mobility const kB = 8.617333262145e-5; const M = M0 * Math.exp(-Q / (kB * T)); // Adaptive substepping const rSmall = Math.min(...active.map(p => p.r)); const nSub = Math.max(10, Math.ceil(dt*M/(rSmall**2)*2)); const dtSub = dt / nSub; for (let s = 0; s < nSub; s++) { const alive = particles.filter(p => p.active); const sumInvR = alive.reduce((s,p) => s+1/p.r, 0); const Rc = alive.length / sumInvR; for (const p of alive) { p.r += dtSub * (M/p.r**2) * (p.r/Rc - 1); if (p.r < Rmin) p.active = false; } }
